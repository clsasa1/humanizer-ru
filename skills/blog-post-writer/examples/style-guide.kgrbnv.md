## Голос и тон автора

### Главные принципы

1. **Искренность и уязвимость** — автор не боится признаваться в своих слабостях, страхах, сомнениях
2. **Экспертность без надменности** — делится знаниями, но не поучает
3. **Энтузиазм** — искренне радуется технологиям и открытиям
4. **Практичность** — даёт конкретные советы, инструменты, ссылки

### Характерные фразы и обороты

| Эмоция/Ситуация | Примеры фраз |
|-----------------|--------------|
| Восторг | "АААААААА!", "Пушка!", "Просто вау!", "Ну что это, если не чудо" |
| Переход | "Короче...", "Итак...", "Так вот..." |
| Честность | "Сорри за кликбейт, но...", "Если честно...", "Не то чтобы я..." |
| Вопрос к читателям | "Согласны?", "Есть у меня здесь кто-то, кто...?", "Давайте обсудим в комментариях!" |
| Самоирония | "~~можно всем при любом удобном случае говорить~~" |
| Призыв к действию | "Приходите!", "Залетайте!", "Присоединяйтесь!" |

### Языковые особенности

- **Первое лицо** — всегда от "я", личный опыт
- **Микс языков** — русский + английские термины (AI, LLM, SaaS, deep research)
- **Разговорный стиль** — "дофига", "пиздец", "офигенный", "классный"
- **Акцентное выделение** — CAPS LOCK для эмоционального усиления

## Форматирование постов

### Заголовки

**Стандартный вариант** — жирным в начале поста:

```
**Название поста**
```

**Лёгкий вариант** — без жирного, особенно когда есть вводная фраза:

```
Ну и вдогонку из серии "я не создан для аналогового мира".

Как я отправлял бумажное письмо
```

Используй лёгкий вариант для разговорных, бытовых историй — меньше визуального "шума".

### Разделители секций

Тире на отдельной строке:

```
—
```

### Списки

**Буллеты с эмодзи:**
```
▫️ пункт первый
▫️ пункт второй
▫️ пункт третий
```

**Нумерованные (для пошаговых инструкций):**
```
01 первый пункт
02 второй пункт
03 третий пункт
```

**Нумерованные словами (для историй с перечислением):**
```
Первое. Описание первого пункта.

Второе. Описание второго пункта.

Третье. Описание третьего пункта.
```

Без жирного — для лёгких, разговорных постов.

### Ссылки

Всегда с эмодзи 🔗:

```
🔗 [Название ссылки](https://example.com)
```

### Хештеги

В конце поста, если это серия:

```
#ВоскресныйДайджест
#СтрашноПризнаться
```

### Выделение текста

- **Жирный** — для важных мыслей, названий, акцентов
- __Подчёркивание__ — для особого выделения внутри абзаца
- ~~Зачёркнутый~~ — для самоиронии

## Типы постов

### 1. Воскресный дайджест (#ВоскресныйДайджест)

**Структура:**
```
**Воскресный дайджест #[номер]**

[Личный апдейт — 1-2 предложения о прошедшей неделе]

—

[Новость/ссылка 1 с кратким комментарием]

🔗 [Источник](url)

—

[Новость/ссылка 2]

🔗 [Источник](url)

—

[... ещё 3-5 ссылок ...]

—

Предыдущие выпуски:

#ВоскресныйДайджест
```

**Примеры тем:**
- AI-новости (OpenAI, Anthropic, Google)
- Стартап-экосистема
- Интересные статьи и видео
- Собственные анонсы (воркшопы, продукты)
- Рекомендации (каналы, сервисы)

### 2. Страшно признаться (#СтрашноПризнаться)

**Структура:**
```
**[Провокационный заголовок]**

серия #СтрашноПризнаться, эпизод [N]

[Уязвимое признание — что-то, что автор обычно скрывает]

[Развитие темы — почему это важно, как осознал]

[Выводы или отсутствие выводов — "Здесь нет никакого вывода. Буду разбираться..."]

Есть у меня здесь кто-то, кто такое же замечал за собой?
```

**Примеры тем:**
- Отношения с едой
- Страх дискомфорта
- Фиксация на деньгах
- Синдром самозванца

### 3. Личный опыт / Размышления

**Структура:**
```
**[Заголовок]**

[Контекст — что случилось]

[Развитие — детали, рефлексия]

[Выводы — что понял, что изменилось]

—

[Опционально: вопрос к читателям или ссылка]
```

**Примеры:**
- "Два года назад я перестал пить любой алкоголь"
- "Как я решил заниматься спортом каждый день"
- "Культура в компаниях переоценена"

### 4. Образовательный контент про AI

**Структура:**
```
**[Заголовок — тезис или инсайт]**

[Введение — почему это важно]

[Основная часть — объяснение, примеры]

▫️ пункт 1
▫️ пункт 2
▫️ пункт 3

[Практическое применение]

—

🔗 [Ссылка на ресурс/воркшоп]
```

### 5. Анонсы воркшопов/продуктов

**Структура:**
```
**[Заголовок — что и когда]**

[Контекст — зачем это нужно]

[Что будет на воркшопе/в продукте:]

▫️ пункт 1
▫️ пункт 2
▫️ пункт 3

[Social proof — отзывы, цифры]

[Призыв к действию]

🔗 [Регистрация/сайт](url)
```

### 6. Путешествия

**Структура:**
```
**[Название места]**

[Где это, когда был]

[Что понравилось — конкретно]

[Сравнения с другими местами]

[Практические советы]

[Вердикт и рекомендация]
```

### 7. Бытовая история / Лёгкий пост

**Когда использовать:** забавные случаи из жизни, бытовые наблюдения, самоирония

**Особенности форматирования:**
- Минимум жирного (или вообще без него)
- Вводная фраза может идти ДО заголовка
- Нумерация словами без выделения
- Эмодзи только если органично (в конце)

**Структура:**
```
[Вводная фраза — серия или контекст]

[Заголовок без жирного]

[История — разбита на короткие абзацы]

[Перечисление если есть — словами: Первое. Второе. Третье.]

[Развязка]

—

[Философский вывод или ирония в конце]
```

**Примеры тем:**
- Аналоговый мир (почта, бумаги, бюрократия)
- Бытовые неудачи с самоиронией
- Культурные различия (Лондон vs Россия)

---

### Личные истории (#ТутТакоеБыло и подобные)

**Главное правило:** писать как рассказываешь историю за столом — НЕ литературно.

**Что отличает хорошую личную историю:**

1. **Реальные имена и ссылки** — не "один из друзей", а "Лёха Иванов". Не "незнакомая девушка", а "Лера Дергилева". Ссылки на каналы, инсту, посты — если они есть.

2. **Смешные детали-отступления** — маленькие неловкие подробности, которые другие бы скрыли. Например: "попросил общего друга подписаться на меня в Инсте, чтобы повысить вероятность ответа, хаха". Это золото.

3. **Живая эмоция в тексте** — "Вы че, охренели? Это же Каста." — не "я был в шоке". Писать реакцию как она есть, в разговорной лексике.

4. **Эмодзи точечно** — не в каждом абзаце, а в моментах иронии или смягчения (😅 😁 😂 ¯\_(ツ)_/¯). Усиливают, а не украшают.

5. **Описание персонажей через детали** — не "интересный человек", а "говорили, что она немного отлетевшая по практикам и эзотерике ¯\_(ツ)_/¯"

6. **Не нужны литературные паузы** — короткие строки ради драматизма ("Тишина." на отдельной строке) — не в стиле. История сама несёт нужный ритм через детали.

7. **Вывод — не мораль, а наблюдение** — не "я понял, что..." а "вот сколько случайностей должно было произойти" и перечисление. Без поучений.

### 8. Книги / Обзоры

**Структура:**
```
**[Название книги]**

[О чём книга — 2-3 предложения]

[Главный инсайт — что зацепило лично]

[Как это применимо к жизни]

—

Согласны? Или считаете, что чушь? Давайте обсудим в комментариях!

🔗 [Литрес](url)
```

```
Рынок станет перенасыщенным, и конкуренция еще сильнее сместится в плоскость **маркетинга и продаж.**

Продукты и сервисы окончательно станут у всех одинаковые, порог входа в их создание станет нулевым, зато продвигать будет очень сложно.

При этом ИИ еще долго не сможет создавать __смыслы__ в их маркетинговом понимании, не сможет креативить на уровне крутых специалистов.

Да, он уже неплохо справляется с аналитикой, с перфомансом, но не с креативом как таковым.

Маркетологи, наступает ваше время. It's time to promote things, baby.
```

### Пример 4: Лёгкий разговорный пост (минимум форматирования)

```
Ну и вдогонку из серии "я не создан для аналогового мира".

Как я отправлял бумажное письмо

Конверта у меня не было. Распечатал документы, пришёл на почту, взял талончик. Пока ждал очереди — увидел на стене конверты в продаже. Купил пачку А4, пять штук. Ну как купил? Просто взял и решил, что потом оплачу.

Первое. Можно было купить не пять конвертов, а один. Они есть у сотрудников почты. А я купил сразу пять.

Второе. Оказывается, слева вверху пишется ОТ КОГО. А справа внизу — КОМУ. То есть наоборот.

Но знаете, в этом всё-таки есть какая-то романтика — обмениваться бумажными письмами. Так что какая-то часть меня даже признательна лондонской бюрократии за необходимость отправлять письма по настоящей аналоговой почте 😇
```

- Минимум форматирования — текст говорит сам за себя
- Эмодзи только в конце, органично
