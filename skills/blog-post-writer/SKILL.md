# Blog Post Writer

Помогает автору писать посты для его личного Telegram-канала в его реальном голосе — а не в усреднённом AI-стиле.

## Главный принцип

**Никогда не пишу пост без чтения архива канала.** Без архива результат сухой и безличный. С архивом — попадает в голос автора.

## Что делаю при запросе «напиши пост»

1. **Ищу архив постов автора:**
   - Если в проекте есть `references/posts-archive.md` или `references/style-guide.md` рядом с этим скиллом — использую их.
   - Если их нет, но в папке проекта (или прикреплён к чату) есть CSV-файл — это, скорее всего, экспорт канала из [@ToCsvBot](https://t.me/ToCsvBot). Читаю его, отфильтровываю короткие сообщения (<200 символов), репосты и сообщения без осмысленного текста, остальное — материал для работы.
   - Если ничего нет — спрашиваю автора, где архив его постов.

2. **Если это первая встреча с архивом** — предлагаю автору сначала пройтись по нему и собрать внутренний гайд по стилю. Сохраняю его в `references/style-guide.md` рядом со скиллом. В следующий раз не нужно будет перечитывать весь архив — это быстрее и точнее.

   Что включить в гайд:
   - Характерные фразы и обороты автора
   - Типы постов, которые он пишет, и их типичная структура
   - Как автор форматирует: заголовки, разделители, эмодзи, выделения, списки
   - Темы и ценности, которые проявляются в постах
   - 3-5 постов разных типов целиком как референс

3. **Пишу пост:**
   - Определяю тип (см. ниже)
   - Держусь голоса из архива — лексика, ритм, длина абзацев, форматирование
   - Закладываю вопрос к читателям или CTA в конце, если автор так делает
   - Не лью воду, не клиширую, не добавляю морали без необходимости

4. **Перед отдачей** прогоняю по чеклисту в конце этого файла.

## Типичные типы постов в личных каналах

| Тип | Когда |
|-----|-------|
| Дайджест / подборка | Регулярная подборка ссылок недели |
| Уязвимое признание | Личная тема, в которой автор открывается |
| Размышление / опинион | Тезис + аргументы |
| AI / Tech | Обзор инструмента, инсайт |
| Анонс | Мероприятие, продукт, воркшоп |
| Путешествие | Место, поездка |
| Книга / обзор | Разбор книги или продукта |
| Бытовая история | Забавный случай, самоирония |

Конкретные структуры под каждый тип беру из архива — они у каждого автора свои.

## Базовые принципы голоса личного блога

(Это общие принципы. Конкретику — фразы, ритм, темы — беру из архива конкретного автора.)

- **Первое лицо** — пост от «я», личный опыт
- **Уязвимая честность** — реальные сложности, а не только победы
- **Энтузиазм** — искренняя реакция, без вылизанности
- **Практичность** — конкретные инструменты, ссылки, примеры
- **Разговорный язык** — как рассказываешь другу за столом, а не как пишешь в корпоративный блог

## Анти-паттерны (чего НЕ делать)

1. **Не пишу без чтения архива.** Главное правило.
2. **Не использую клише** — «в современном мире», «в эпоху технологий», «давайте поговорим о», «не секрет, что». Если в архиве этого нет — значит, не надо.
3. **Не объясняю очевидное.** Аудитория канала уже в контексте.
4. **Не лью воду.** Если можно сократить вдвое без потери смысла — сокращаю.
5. **Не вылизываю выводы.** Лучше «здесь нет вывода, я сам разбираюсь» — чем выдуманная мораль.
6. **Не использую эмодзи через каждую строчку.** Один-два в нужном месте — лучше десяти размазанных.
7. **Не выдумываю факты об авторе.** Если в архиве не сказано, что он живёт в Лиссабоне или пьёт макиато — не добавляю.

## Чеклист перед отдачей пользователю

- [ ] Голос совпадает с архивом — это не AI-канцелярит
- [ ] Длина и ритм похожи на типичный пост автора
- [ ] Форматирование под выбранный тип
- [ ] Если в архиве используются хештеги серий — добавлен подходящий
- [ ] Вопрос к читателям или CTA, если автор так делает
- [ ] Нет клише, нет морализаторства, нет придуманных фактов
