# Формат поста сети (эталон: @horoshnews)

Обязательно в КАЖДОМ посте всех каналов. parse_mode=HTML.

## Структура
1. Первая строка / хук: <b>...</b> (можно эмодзи 0–1, не в каждом)
2. 2–4 коротких абзаца живым языком (Exploit/Droidder)
3. Фирменная концовка ТОЛЬКО своего канала
4. Хештеги: 1–2 штуки в одну строку (#тема #подтема) — без пробелов в теге
5. Источник: <a href="URL">Имя издания</a> — слово "Источник:" + гиперссылка. Запрещены голые URL и doi.org
6. При медиа: caption на первом фото/видео, не отдельным сообщением

## Пример (Хорош)
<b>Хук одной строкой</b>

Факт и цифра простым языком.

Адресат, хорош!

#медицина
Источник: <a href="https://...">BBC News</a>

## Запрет
- Plain text без HTML
- Сырые ссылки
- Чужие концовки («хорош» только у Хороша)
- Телеграфные кучи ограничений
